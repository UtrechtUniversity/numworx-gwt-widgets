# numworx-gwt-widgets

## Introduction

In this project all GWT Widgets are build. These are used in the cdn server, referenced by the numworx-dwo-project web server.

## Prerequisites

These maven projects depend on the `numworx-dwo-project` repository and its dependencies.

## Contents 

### Folder structure

Each folder contains a HTML5 implementation of a Numworx widget. These widgets correspond to java widgets in `numworx-dwo-author` github project.

### File formats 

All Java, compile to javascript with [GWT](https://www.gwtproject.org) 

## Usage

After compilation and installation each widget goes into the `apps` web archive of the `numworx-dwo-resources` project.
